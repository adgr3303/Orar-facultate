# Orar Facultate

PWA pentru iPhone bazată pe orarul furnizat.

## GitHub Pages
În repository: **Settings → Pages → Deploy from branch → main → / (root) → Save**.

După publicare, aplicația va fi disponibilă la:
https://zax3303.github.io/Orar-facultate/

Pe iPhone: deschide linkul în Safari → Share → Add to Home Screen.
